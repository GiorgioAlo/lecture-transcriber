🎥 Accesso Webex
nessun file

Per scaricare una lezione Webex devi caricare i cookie. Li uso solo per il download, non li salvo: vanno ricaricati ogni volta (scadono in fretta).

  1. Installa l'estensione Get cookies.txt LOCALLY (Chrome o Edge).
  2. Apri il link della registrazione Webex nel browser e accedi (aprila).
  3. Clicca l'icona dell'estensione e premi Export.
  4. Parte il download di un file (di solito chiamato come il sito, es. politecnicomilano.webex.com_cookies.txt).
  5. Torna qui, premi Carica cookies e scegli quel file.

        Benvenuto 👋

        Per trascrivere le lezioni serve una chiave API di Google Gemini (gratuita). La incolli una volta sola: resta salvata in modo sicuro sul tuo computer (Gestore Credenziali di Windows), mai in un file.

        1. Apri Google AI Studio e accedi col tuo account Google.
        2. In alto a destra clicca Crea chiave API.
        3. Dai un nome alla chiave (va bene quello già proposto, Gemini API Key).
        4. Scegli un progetto: se non ne hai, clicca Crea progetto, dagli un nome e crealo; se ne hai già uno, selezionalo.
        5. Conferma: la chiave appare a schermo — copiala.
        6. Torna qui, incollala nel campo qui sopra e premi Salva e continua.

        Impostazioni

        La tua chiave API di Google Gemini, salvata in modo sicuro sul PC.
